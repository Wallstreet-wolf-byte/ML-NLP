# 财经数据采集平台 · 数据获取指南

本指南说明如何使用本项目获取**不同种类**的财经资讯与数据，重点覆盖金银（黄金/白银）和恒指期货等品种。

---

## 一、平台能获取什么

项目已从「纯快讯爬虫」升级为「多维度财经数据采集平台」，共六大类数据：

| 数据维度 | pipeline 参数 | 说明 |
|---------|--------------|------|
| 7x24 快讯 | `flash` | 财联社/金十/华尔街见闻/汇通/证券时报，含品种打标 |
| 实时行情 | `market` | 东方财富 push2，覆盖股票/指数/期货/外汇/贵金属 |
| 资金流向 | `fundflow` | 北向/南向资金、ETF 持仓 |
| 宏观日历 | `macro` | 经济数据发布日历 + 冲击评分 |
| 技术指标 | `technical` | MA/布林带/RSI/MACD/ATR + 金银比等（基于历史日线） |
| 公告数据 | `cninfo` | 巨潮资讯公告（需 token，默认关闭） |

## 二、环境准备与配置

### 2.1 安装依赖

```powershell
cd finance_news_crawler
python -m pip install -r requirements.txt
```

### 2.2 配置 API Key（可选但推荐）

所有 Key 统一在 `config.yaml` 的 `api_keys` 段配置：

```yaml
api_keys:
  tushare_token: ""          # TuShare Pro Token（历史日线/技术指标必需）
  tdx_api_key: ""            # 通达信 API Key
  ifind_api_key: ""          # 同花顺 iFinD
  finnhub_api_key: ""        # Finnhub
  alphavantage_api_key: ""   # Alpha Vantage
  llm_api_key: ""            # DeepSeek/OpenAI
```

> **TuShare Token 获取**：注册 https://tushare.pro ，在「个人主页 → 接口TOKEN」复制。
> 填了 token 后，技术指标会用**真实历史日线**计算；不填则技术指标跳过（不编造数据）。

## 三、快速开始：按品种获取资讯

在 `finance_news_crawler` 目录下运行。

### 3.1 金银（黄金/白银）

```powershell
# 金银相关快讯（含美联储降息等宏观驱动资讯，自动关联）
python main.py --pipeline flash --symbol GC,SI

# 金银全维度（资讯+行情+资金+宏观+技术）
python main.py --pipeline all --symbol GC,SI

# 金银实时行情
python main.py --pipeline market --symbol GC,SI
```

### 3.2 恒指期货 / 港股

```powershell
# 港股相关快讯
python main.py --pipeline flash --market 港股

# 港股全维度
python main.py --pipeline all --market 港股

# 恒生指数实时行情
python main.py --pipeline market --symbol HSI
```

### 3.3 只看某一类数据

```powershell
python main.py --pipeline market       # 只要实时行情
python main.py --pipeline fundflow     # 只要资金流向
python main.py --pipeline macro        # 只要宏观日历
python main.py --pipeline technical    # 只要技术指标
python main.py --pipeline flash        # 只要快讯（全品种）
```

## 四、筛选参数说明

| 参数 | 取值示例 | 说明 |
|------|---------|------|
| `--pipeline` | `all` / `flash` / `market` / `fundflow` / `macro` / `technical` | 选择数据维度 |
| `--symbol` | `GC,SI,HSI,VIX` | 按品种代码筛选（逗号分隔） |
| `--market` | `A股` / `港股` / `美股` / `全球` | 按市场筛选 |
| `--asset-class` | `期货` / `现货` / `外汇` / `债券` / `指数` / `股票` | 按品种大类筛选 |
| `--source` | `all` / `jin10` / `cls` / ... | 快讯来源（仅 flash pipeline） |

> **筛选规则**：宽匹配 + 可重叠 + 不遗漏。
> 例：`--symbol GC` 会同时命中「COMEX黄金大涨」和「美联储降息」（因降息影响金价，自动关联）。
> 一条资讯可归属多品种，但不会漏掉该品种的关联信息。

## 六、数据源体系与回退逻辑

| 数据源 | 类型 | 接入方式 | 优先级 |
|--------|------|---------|--------|
| 东方财富 push2 | 实时行情 | 免费 HTTP API | 主力（实时） |
| 新浪财经 | 实时行情 | 免费 HTTP API | 备用（东方财富失败时） |
| TuShare | 历史日线 | HTTP API（需 token） | 技术指标历史数据 |
| 通达信 TDX | 实时/K线 | 本地 HTTP 服务（需客户端） | 可选增强 |

- **实时行情**：东方财富 → 新浪财经 两级回退。
- **历史日线**：TuShare（token 配置后自动启用）。
- **通达信**：需本机运行「支持 TQ 的通达信客户端」，`config.yaml` 中 `tdx.enabled` 设为 `true` 后可用，覆盖 A股/港股/国内期货。

## 七、典型使用场景

### 场景 A：盘前快速看金银

```powershell
# 金银实时行情 + 技术指标
python main.py --pipeline market --symbol GC,SI
python main.py --pipeline technical --symbol GC,SI
```

### 场景 B：恒指期货日内跟踪

```powershell
# 港股快讯 + 行情 + 南向资金
python main.py --pipeline all --market 港股
```

### 场景 C：宏观事件驱动（非农/CPI 前后）

```powershell
# 只看高影响宏观事件

```

### 场景 D：定时全量采集

在 `config.yaml` 设置 pipeline 开关后，配合计划任务定时运行：

```powershell
python main.py --pipeline all
```


## 九、常见问题

### Q1：技术指标没有输出？
未配置 TuShare token 或品种无历史数据时，技术指标会跳过（不编造数据）。配置 `api_keys.tushare_token` 即可。

### Q2：金银行情偶尔拿不到？
东方财富免费接口有随机限流，已内置重试+间隔。若需稳定高频数据，建议配置 TuShare/通达信做交叉校验。

### Q3：如何新增一个品种？
1. 在 `common/entity_matcher.py` 的 `SYMBOL_ENTITIES` 加品种及关键词。
2. 在 `config.yaml` 的 `market_data.categories` 加行情 secid。
3. （可选）在 `tushare.symbol_map` 加历史数据映射。
