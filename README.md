# ML-NLP
面向量化研究的财经新闻采集、清洗与文本分析项目

本项目在本地研究环境中参考并使用了：中文金融情感词典_姜富伟等(2020).xlsx

- 词典名称：中文金融情感词典
- 参考文献：
Fuwei Jiang, Joshua Lee, Xiumin Martin, and Guofu Zhou.“Manager Sentiment and Stock Returns” Journal of Financial Economics 132(1), 2019,126-149
姜富伟、孟令超、唐国豪，“媒体文本情绪与股票回报预测”，《经济学(季刊)》，2021年第4期，第1323-1344页
- 原始下载链接：https://github.com/MengLingchao/Chinese_financial_sentiment_dictionary
- 使用方式：仅作为本地金融文本情绪研究的外部参考资源，用于新闻文本的情绪词匹配、特征构造和研究性分析。
