# finance_news_crawler 与 finance_news_analysis 合并与 NLP 研究路线

## 1. 东方财富搜索接口为什么会停

`finance_news_analysis` 里的东方财富逻辑，不是“按时间把全量新闻爬完”，而是“按关键词搜索新闻”。

它的实际行为是：

```text
给定关键词 -> 请求搜索接口 -> 取第一页或少量结果 -> 转成 NewsItem
```

当前代码里更接近下面这种模式：

- 关键词列表是固定的
- 每个关键词只取少量结果
- 没有做“从头翻到尾”的全量时间分页
- 没有用“结束时间”作为硬停止条件

所以它的停止方式不是“爬到某个时间就停”，而是：

```text
关键词跑完了 / 当前页结果跑完了 / 达到每个关键词的条数上限
```

### 这意味着什么

它不是天然适合“完整日频归档”的工具，更适合：

- 主题补充抓取
- 关键词定向搜集
- 日内某主题热度跟踪

### 如果要改成日频

可以加一个时间过滤层：

```text
1. 先按关键词搜
2. 取回结果后按 article_date 过滤
3. 只保留当天或指定时间区间的新闻
4. 必要时翻页直到日期早于 start_date
```

也就是说，**它现在不是默认只爬当天新闻，而是默认抓关键词命中的相关新闻**。  
如果要做严格日频，就要再补时间边界。

## 2. 板块分类的目的是什么

代码里的“市场分类”和“板块分类”不是为了炫技，而是为了把文本变成可回测的结构化特征。

### 市场分类的作用

比如把新闻归到：

```text
A股 / 港股 / 美股 / 黄金 / 白银 / 期货 / 其他
```

这样可以做：

- 市场维度的新闻热度
- 市场维度的情绪统计
- 不同市场的事件冲击比较
- 资产联动分析

例如：

```text
美联储降息预期升温，黄金上涨，美股期货走强
```

可以同时归到：

- 美股
- 黄金期货

这比“只看一条新闻情绪”更适合因子研究。

### 板块分类的作用

比如把新闻归到：

```text
半导体 / 新能源 / 医药 / 房地产 / 银行 / 证券 / 消费 / 军工 / 科技 / 能源 / 贵金属 / 农业 / 汽车 / 地产建材
```

这样可以做：

- 行业热度因子
- 行业情绪因子
- 主题轮动信号
- 事件对行业的映射

例如：

```text
芯片、光刻、晶圆、中芯国际 -> 半导体
锂电池、光伏、储能、比亚迪 -> 新能源
```

### 核心价值

板块分类的本质是：

```text
把自然语言事件，变成“市场/行业暴露”
```

这样后面才能做：

- 按行业聚合情绪
- 按主题统计热度
- 按板块做回测
- 按板块做轮动研究

## 3. 两个仓库怎么合并

建议不要直接把两个仓库“粗暴拼接”，而是做一次清理式整合。

### 第一步：先保留各自最有价值的部分

#### 从 `finance_news_crawler` 保留

- 汇通财经爬虫
- 金十数据爬虫
- 华尔街见闻爬虫
- 统一时间区间配置
- 金十 VIP / 图示过滤
- 输出排序
- 结构化 JSON

#### 从 `finance_news_analysis` 保留

- 情绪词典框架
- 市场分类规则
- 板块分类规则
- 影响等级评估
- Web 展示思路
- 可选 LLM 分析入口

### 第二步：删除或延后不必要部分

如果目标是中低频量化与 NLP 因子研究，第一版可以先不保留：

- 过重的 Web 展示
- 多余的 LLM 自动总结
- 过多外部 API 依赖
- 还没验证价值的金融 API 扩展

### 第三步：统一数据结构

两个项目要合并，最关键是统一新闻对象。

建议统一成一个基础 schema：

```json
{
  "id": "",
  "title": "",
  "content": "",
  "publish_time": "",
  "crawl_time": "",
  "source": "",
  "data_source": "",
  "data_frequency": "",
  "sentiment_label": "",
  "sentiment_score": 0.0,
  "markets": [],
  "sectors": [],
  "importance_score": 0.0
}
```

### 第四步：推荐的合并后结构

```text
ML-NLP/
  finance_news_crawler/          # 7x24 新闻采集
  sentiment_analysis/            # 词典、分类、影响、板块
  nlp_analysis/                  # TF-IDF、Word2Vec、BERT
  factor_builder/                # 日频/周频因子生成
  data/
    raw/
    clean/
    features/
    factors/
  docs/
```

### 第五步：合并方式建议

1. 先把 `finance_news_analysis` 里有用的 analyzer 代码单独迁移出来
2. 再让 `finance_news_crawler` 的输出接入这些分析器
3. 最后再考虑 Web 看板和更复杂的模型

### 合并原则

```text
采集层独立
分析层独立
特征层独立
展示层可选
```

这样后面才方便维护，也方便扩展股吧、年报、公告、社媒等新来源。

## 4. 未来 NLP 项目可以怎么用

你现在看到的公募基金、量化私募做的另类数据，核心思路通常不是“只做情绪”，而是把文本转成可回测的结构化特征。

对我们来说，NLP 未来可以分成四类应用。

### 4.1 基本面选股

适合中低频。

思路是从新闻、公告、年报、股吧中提取：

- 盈利改善
- 业绩预期
- 风险暴露
- 行业景气
- 市场关注度

可以构造因子：

```text
sentiment_factor
policy_factor
industry_heat_factor
risk_factor
growth_factor
```

用途：

- 选股
- 行业轮动
- 主题轮动
- 中期持有

### 4.2 择时

适合日频到周频。

核心是看：

- 市场情绪是否过热
- 风险事件是否集中爆发
- 新闻热度是否异常
- 多空分歧是否放大

可以构造：

```text
market_sentiment_index
breaking_news_index
attention_zscore
disagreement_score
```

用途：

- 仓位增减
- 风险开关
- 指数趋势判断

### 4.3 事件驱动

适合短线到中频。

核心是：

- 某个事件来了
- 哪些资产最受影响
- 多久后市场反应

比如：

- 降息
- 加息
- 关税
- 制裁
- 事故
- 业绩预告
- 回购增持

用途：

- 突发事件监控
- 盘中解释
- 短线交易辅助

### 4.4 因子模型

这是你最值得主攻的方向。

把 NLP 输出变成横截面特征，比如：

```text
stock_daily_sentiment
stock_attention_score
sector_heat_score
event_burst_score
topic_tfidf_score
guba_disagreement_score
news_guba_consensus_score
```

这些因子可以拿去做：

- IC / IR 测试
- 分组回测
- 横截面回归
- 行业轮动回测
- 组合优化

### 4.5 怎么理解“服务于基本面还是择时”

答案是：

```text
两者都可以，但层级不同。
```

#### 基本面方向

更适合：

- 新闻因子
- 公告因子
- 年报文本
- 股吧情绪

用于：

- 选股
- 行业配置
- 中低频持有

#### 择时方向

更适合：

- 7x24 快讯
- 突发事件
- 风险事件
- 市场情绪指数

用于：

- 仓位控制
- 风险预警
- 指数择时

### 最实用的判断

你不需要一开始就决定“只能做选股还是只能做择时”。

更合理的路线是：

```text
新闻流 -> 事件因子 -> 行业/个股因子 -> 回测
```

先把因子做出来，再看它更适合基本面选股，还是适合择时。

## 5. 推荐的下一步

### 短期

1. 提取 `finance_news_analysis` 里有价值的分析模块
2. 接入当前 `finance_news_crawler` 的输出
3. 统一新闻 schema
4. 继续保留情绪词典和板块分类

### 中期

1. 建立长期语料库
2. 引入 TF-IDF
3. 引入 Word2Vec
4. 做日频/周频因子表

### 长期

1. 加入股吧情绪
2. 加入年报文本
3. 做事件聚类
4. 做回测和 IC/IR 评估
5. 逐步引入 BERT 类模型

## 6. 一句话总结

`finance_news_analysis` 的价值不在于它本身已经“完美”，而在于它给了我们一个很好的 NLP 雏形：

- 东方财富搜索接口
- 词典情绪分析
- 市场/板块分类
- 影响等级评估

配合我们现在的 7x24 新闻爬虫，可以升级成一个更完整的：

```text
财经新闻采集 + NLP 特征生成 + 中低频量化因子研究平台
```
