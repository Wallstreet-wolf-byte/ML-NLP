# 财经 NLP 项目的落地应用方向

## 背景

当前项目已经具备 7x24 财经新闻采集能力，并且已经讨论过引入：

- 情绪词典
- 市场分类
- 板块分类
- TF-IDF
- Word2Vec
- BERT
- 股吧/东方财富舆情

但仅仅判断一条新闻是“整体利多”还是“整体利空”是不够的。财经文本的影响通常具有明显的资产差异。

例如：

```text
美联储降息预期升温
```

它可能意味着：

```text
黄金：利多
美元：利空
美股：短期利多
银行：可能利空
```

所以未来项目不能停留在：

```text
这条新闻是利好还是利空
```

而应该升级为：

```text
这条新闻对哪个资产利好？
对哪个资产利空？
影响强度多大？
影响是短期还是中期？
是否已经被市场消化？
```

## 为什么整体情绪太片面

“整体利多/利空”存在几个问题：

1. 不区分资产
2. 不区分市场
3. 不区分短期和中期
4. 不区分是否已经 price in
5. 无法直接回测
6. 很难形成可交易信号

例如：

```text
油价大涨
```

它对不同资产的影响可能完全不同：

```text
原油：利多
油气公司：利多
航空公司：利空
通胀预期：利多
利率债：可能利空
```

因此，财经 NLP 应该从“文本情绪”升级为“资产定向影响”。

## 三种落地方式

### 1. 服务某一类期货品种交易

这是当前 7x24 新闻流最适合的方向之一。

适合研究的资产包括：

```text
黄金
原油
铜
白银
股指期货
恒指期货
美元指数
人民币汇率
```

这些品种对宏观、政策、地缘、库存、央行信息比较敏感。

#### 原油示例

```text
OPEC 减产 -> 原油偏利多
库存增加 -> 原油偏利空
中东冲突 -> 原油偏利多
全球经济放缓 -> 原油偏利空
美元走强 -> 原油承压
```

#### 黄金示例

```text
降息预期 -> 黄金偏利多
美债收益率下行 -> 黄金偏利多
美元走强 -> 黄金偏利空
地缘冲突 -> 黄金偏利多
通胀超预期 -> 需要结合实际利率判断
```

最终应该输出：

```json
{
  "asset": "黄金",
  "impact_direction": "positive",
  "impact_strength": 0.72,
  "reason": ["降息预期", "地缘风险"]
}
```

可以构造的因子：

```text
gold_news_sentiment
oil_news_sentiment
copper_news_sentiment
hsi_news_sentiment
usd_cnh_news_sentiment
```

### 2. 做舆情监测系统

这是最容易落地、最容易展示的方向。

目标不是直接交易，而是让系统回答：

```text
今天发生了什么？
哪些资产受到影响？
哪些主题正在升温？
哪些风险值得关注？
哪些新闻可能比较重要？
```

舆情监测系统可以展示：

```text
市场总览
高影响新闻
资产情绪雷达
主题热度变化
风险事件列表
多来源重复事件
```

这个方向的优点：

- 不需要立刻证明能赚钱
- 可以先证明信息组织能力
- 适合作为研究平台
- 适合作为项目展示
- 后续可以自然扩展到因子研究

### 3. 做中低频新闻因子研究

这是更偏量化研究的方向。

可以按日生成：

```text
gold_sentiment_daily
oil_sentiment_daily
hsi_sentiment_daily
a_share_policy_sentiment_daily
sector_heat_daily
risk_event_daily
```

然后做回测：

```text
今日新闻情绪 -> 明日收益
过去3日新闻热度 -> 未来5日收益
风险事件升温 -> 波动率上升
情绪极端 -> 反转
```

最终可以服务：

- 择时
- 行业轮动
- 资产配置
- 期货方向判断
- 风险控制

## 推荐优先聚焦的资产

不建议一开始做全市场股票情绪，因为股票太多、噪声太大、映射关系复杂。

更建议先聚焦：

```text
黄金
原油
恒指
A股指数
美元/人民币
铜
```

原因：

- 宏观新闻对这些资产影响更直接
- 7x24 新闻对这些资产更有效
- 不需要覆盖几千只股票
- 解释性更强
- 更容易和行情数据对齐

## 核心升级方向：资产定向情绪

当前粗粒度结果可能是：

```json
{
  "sentiment": "利好"
}
```

未来应该升级为：

```json
{
  "asset_impacts": [
    {
      "asset": "黄金",
      "direction": "positive",
      "strength": 0.8,
      "reason": ["降息预期", "避险需求"]
    },
    {
      "asset": "美元",
      "direction": "negative",
      "strength": 0.5,
      "reason": ["降息预期"]
    }
  ]
}
```

这样才能真正服务交易和因子研究。

## 如果选择期货品种交易方向

第一版可以先做黄金和原油。

### 新闻分类

每条新闻先归入事件类别：

```text
宏观利率
美元
通胀
地缘政治
供需库存
OPEC
央行
经济衰退
```

### 资产影响映射

规则示例：

```text
地缘冲突 -> 黄金利多，原油利多
降息预期 -> 黄金利多，美元利空
原油库存增加 -> 原油利空
OPEC 减产 -> 原油利多
美元走强 -> 黄金利空，原油利空
```

### 日频因子

可以生成：

```text
gold_news_sentiment
oil_news_sentiment
gold_risk_score
oil_supply_shock_score
macro_liquidity_score
```

## 如果选择舆情监测方向

第一版可以每天输出：

```text
今日高影响新闻 Top 20
各资产情绪分数
各主题热度变化
风险事件列表
多来源重复事件
昨日 vs 今日情绪变化
```

这种系统可以先作为研究辅助工具，再逐步变成因子生产器。

## 推荐落地路线

### 第一阶段：舆情监测

先让系统回答：

```text
今天发生了什么？
影响哪些资产？
哪些主题升温？
哪些风险值得关注？
```

### 第二阶段：因子研究

把舆情监测结果转成：

```text
日频资产情绪因子
行业热度因子
风险事件因子
```

### 第三阶段：交易验证

接入行情数据，做：

```text
IC
分组回测
胜率
收益回撤
事件窗口分析
```

## 总结

这个项目不应该定位成：

```text
全球财经新闻整体利多利空判断器
```

这个方向太粗，很难直接落地。

更合理的定位是：

```text
面向具体资产的事件情绪识别系统
```

推荐第一个落地场景：

```text
黄金、原油、恒指等宏观敏感资产的新闻舆情监测与中低频情绪因子研究
```

这样最符合当前 7x24 新闻数据的优势，也更容易逐步回测和验证。
