这章回答一个核心问题：

> 机器学习公式不是凭空出现的，它们通常来自“我要优化什么目标”和“我对数据做了什么概率假设”。

## 为什么这部分对机器学习和量化重要

金融工程学生容易熟悉回归公式，但机器学习推导会让人不舒服，因为它常写成：


$$
\hat{\theta} = \arg\min_{\theta} { 1/n \sum_i L(y_i, f(x_i; \theta)) + \lambda R(\theta) }
$$

这其实并不神秘。它的意思是：

```text
找一组模型参数 θ，
让模型在训练样本上的平均错误尽量小，
同时不要让模型太复杂。
```

在量化里：

- 因子模型训练参数，是优化。
- Lasso 选因子，是优化。
- 组合优化，是约束优化。
- 逻辑回归预测上涨概率，是最大似然。
- 交叉熵训练分类模型，是信息论和最大似然的结合。
- PCA 的第一主成分，是带约束的方差最大化。

## 一、机器学习训练的标准形式

最常见公式：


$$
\hat{\theta} = \arg\min_{\theta} { 1/n \sum_{i=1}^n L(y_i, f(x_i; \theta)) + \lambda R(\theta) }
$$

逐项翻译：

| 部分 | 含义 |
|---|---|
| $θ$ | 模型参数，可以是权重、偏置、树参数、神经网络参数 |
| $θ_hat$ | 训练得到的最优参数 |
| $f(x_i; θ)$ | 模型对第 i 个样本的预测 |
| $L(y_i, f(x_i; θ))$ | 第 i 个样本的损失 |
| $1/n Σ$ | 对所有样本求平均损失 |
| $R(θ)$ | 正则化项，惩罚复杂模型 |
| $λ$ | 正则化强度 |
| $argmin$ | 找到让目标最小的参数 |

```mermaid
flowchart LR
    A[输入特征 x] --> B[模型 f(x; θ)]
    B --> C[预测值]
    C --> D[损失函数 L]
    E[真实标签 y] --> D
    D --> F[平均损失]
    G[正则化 R(θ)] --> H[总目标函数]
    F --> H
    H --> I[优化器更新 θ]
```

ASCII 版本：

```text
数据 -> 模型预测 -> 计算损失 -> 加正则化 -> 更新参数 -> 重复
```

## 二、目标函数、损失函数、正则化

### 1. 目标函数

目标函数是训练时真正要最小化或最大化的整体函数。

例如 Ridge：


$$
J(w) = \lVert y - Xw\rVert_2^2 + \lambda \lVert w\rVert_2^2
$$

这里 $J(w)$ 是目标函数。

### 2. 损失函数

损失函数衡量预测错了多少。

| 任务 | 常见损失 | 公式直觉 |
|---|---|---|
| 回归 | 平方损失 | 预测值和真实值差距越大，惩罚越大 |
| 二分类 | 交叉熵 / LogLoss | 真实类别概率越低，惩罚越大 |
| SVM | Hinge Loss | 分类边界不够安全就惩罚 |
| 排序 | Pairwise Loss | 顺序排错就惩罚 |

### 3. 正则化

正则化是为了控制模型复杂度。

可以先把它记成：

$$
\text{总目标} = \text{训练误差} + \text{复杂度惩罚}
$$

| 正则化 | 公式 | 直觉 |
|---|---|---|
| L2 | $λ||w||_2^2$ | 让参数更小、更平滑 |
| L1 | $λ||w||_1$ | 让部分参数变成 0，做稀疏选择 |
| Dropout | 随机丢神经元 | 不让模型过度依赖局部结构 |
| Early Stopping | 提前停止训练 | 防止训练集越拟合越过 |

## 三、梯度下降：沿着下山方向更新参数

### 1. 基本公式


$$
\theta_{t+1} = \theta_t - \eta \nabla J(\theta_t)
$$

逐项翻译：

| 部分 | 含义 |
|---|---|
| $θ_t$ | 第 t 次迭代的参数 |
| $θ_{t+1}$ | 更新后的参数 |
| $η$ | 学习率 |
| $\nabla J(θ_t)$ | 当前参数处的梯度 |
| 减号 | 沿损失下降方向走 |

### 2. 学习率为什么重要

| 学习率 | 现象 |
|---|---|
| 太小 | 训练很慢 |
| 合适 | 稳定下降 |
| 太大 | 来回震荡，甚至发散 |

```text
小步走：慢但稳
大步走：快但可能冲过头
```

### 3. Batch GD、SGD、Mini-batch SGD

| 方法 | 每次用多少数据算梯度 | 优点 | 缺点 |
|---|---|---|---|
| Batch GD | 全部样本 | 梯度稳定 | 大数据很慢 |
| SGD | 一个样本 | 更新快 | 噪声大 |
| Mini-batch SGD | 一小批样本 | 深度学习最常用折中 | 需要调 batch size |

量化里如果样本量不大，普通优化就够；深度学习和大规模文本模型通常依赖 mini-batch。

## 四、凸函数：为什么有些问题容易优化

### 1. 凸函数定义


$$
f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y), 0 \le \lambda \le 1
$$

你不必一开始死背。几何直觉是：

```text
函数图像上任意两点连线，都在函数图像上方。
```

像一个碗：

```text
    \        /
     \      /
      \____/
```

### 2. 为什么 ML 喜欢凸优化

凸函数最大的好处：

```text
局部最优就是全局最优。
```

非凸函数可能像山谷很多：

```text
_/\/\__/\/\_
```

你掉进一个局部低点，不一定是全局最低点。

| 模型/问题 | 是否常见凸优化 |
|---|---|
| 线性回归 | 是 |
| Ridge | 是 |
| Lasso | 是，但 L1 不光滑 |
| 逻辑回归 | 是 |
| SVM | 是 |
| 神经网络 | 通常非凸 |
| K-means | 非凸 |

### 3. 凸性和量化

均值-方差组合优化在标准形式下通常是凸二次优化；这就是为什么它有成熟求解器。但加入复杂交易约束、整数约束、非线性成本后，问题可能变难。

## 五、约束优化、拉格朗日乘子与 KKT

### 1. 什么是约束优化

无约束：


$$
\min_{x} f(x)
$$

有约束：


$$
\begin{gathered}
\min_{x} f(x) \\
\text{s.t.} g(x) = 0
\end{gathered}
$$

`s.t.` 是 subject to，意思是“在满足某条件下”。

量化例子：


$$
\begin{gathered}
\min_{w} w^T \Sigma w \\
\text{s.t.} 1^T w = 1
\end{gathered}
$$

读法：

```text
在组合权重加总为 1 的条件下，让组合方差最小。
```

### 2. 拉格朗日乘子

等式约束问题：


$$
\begin{gathered}
\min_{x} f(x) \\
\text{s.t.} g(x) = 0
\end{gathered}
$$

构造拉格朗日函数：


$$
L(x, \lambda) = f(x) + \lambda g(x)
$$

直觉：

```text
把约束条件揉进目标函数里，让一个带约束问题变成求 L 的驻点问题。
```

PCA 第一主成分：


$$
\begin{gathered}
\max_{w} w^T \Sigma w \\
\text{s.t.} w^T w = 1
\end{gathered}
$$

拉格朗日函数：


$$
L(w, \lambda) = w^T \Sigma w - \lambda(w^T w - 1)
$$

对 $w$ 求导并令为 0，会得到：


$$
\Sigma w = \lambda w
$$

这就是特征值问题。PCA 不是魔法，它是约束优化推导出来的。

### 3. KKT 条件

KKT 是处理带不等式约束优化的重要条件。

标准形式：


$$
\begin{gathered}
\min_{x} f(x) \\
\text{s.t.} g_i(x) \le 0 \\
h_j(x) = 0
\end{gathered}
$$

KKT 条件包括：

| 条件 | 直觉 |
|---|---|
| 原始可行 | 解满足原问题约束 |
| 对偶可行 | 不等式约束乘子非负 |
| 驻点条件 | 拉格朗日函数对变量求导为 0 |
| 互补松弛 | 约束不紧时乘子为 0，约束紧时乘子可能非零 |

你现在不必完整证明 KKT，但要知道它为什么重要：

```text
SVM 的支持向量、间隔最大化、对偶问题都离不开 KKT。
```

## 六、对偶问题与核技巧

### 1. 对偶问题

有时原问题不好解，或者原问题不方便引入核函数，就转成对偶问题。

```text
原问题：直接优化模型参数 w
对偶问题：优化一组样本权重 α
```

SVM 对偶形式里会出现：


$$
\sum_i \sum_j \alpha_i \alpha_j y_i y_j x_i^T x_j
$$

这看起来吓人，其实是在计算样本两两之间的相似度 $x_i^T x_j$，再用 $\alpha_i$、$\alpha_j$ 和标签 $y_i$、$y_j$ 加权。

### 2. 核技巧

核函数：


$$
K(x_i, x_j) = \phi(x_i)^T \phi(x_j)
$$

读法：

```text
先把样本映射到高维空间 φ(x)，再计算高维内积。
但我们不显式计算 φ(x)，而是直接用 K 算相似度。
```

所以 SVM 里：


$$
x_i^T x_j
$$

可以替换成：


$$
K(x_i, x_j)
$$

最终你看到：


$$
\sum_i \sum_j \alpha_i \alpha_j y_i y_j K(x_i, x_j)
$$

就知道它是在算“样本两两加权相似度”。

### 3. 常见核函数

| 核函数 | 形式 | 直觉 |
|---|---|---|
| 线性核 | $K(x,z)=x^Tz$ | 原空间内积 |
| 多项式核 | $K(x,z)=(x^Tz+c)^p$ | 多项式特征相似度 |
| RBF 核 | $K(x,z)=exp(-γ||x-z||^2)$ | 距离越近越相似 |

## 七、MLE：损失函数为什么长那样

### 1. MLE 是什么

MLE 是极大似然估计：


$$
\hat{\theta} = \arg\max_{\theta} P(data | \theta)
$$

读法：

```text
找一组参数 θ，让当前观测到的数据最可能出现。
```

独立样本下：


$$
L(\theta) = \prod_i P(y_i | x_i; \theta)
$$

取对数：


$$
\log L(\theta) = \sum_i \log P(y_i | x_i; \theta)
$$

最大化 log likelihood 等价于最小化 negative log likelihood：


$$
\min_{\theta} -\sum_i \log P(y_i | x_i; \theta)
$$

这就是很多机器学习损失函数的来源。

### 2. 线性回归与正态误差

假设：


$$
\begin{gathered}
y_i = x_i^T w + \varepsilon_i \\
\varepsilon_i \sim N(0, \sigma^2)
\end{gathered}
$$

意思是：

$$
\text{真实值} = \text{线性预测} + \text{正态噪声}
$$

在这个假设下，最大化似然最终等价于：


$$
\min_{w} \sum_i (y_i - x_i^T w)^2
$$

也就是最小二乘。

所以平方损失不是拍脑袋来的，它来自“误差服从正态分布”的概率假设。

### 3. 逻辑回归与伯努利分布

二分类标签：


$$
y_i \in \{0, 1\}
$$

模型输出：


$$
p_i = P(y_i = 1 | x_i; w)
$$

伯努利似然：


$$
P(y_i | x_i; w) = p_i^{y_i}(1-p_i)^{1-y_i}
$$

负对数似然：


$$
L = -\sum_i [ y_i \log p_i + (1-y_i) \log(1-p_i) ]
$$

这就是二分类交叉熵 / LogLoss。

## 八、MAP：正则化的贝叶斯解释

MLE 只看数据：


$$
\arg\max_{\theta} P(data | \theta)
$$

MAP 看数据和先验：


$$
\arg\max_{\theta} P(\theta | data)
$$

由贝叶斯公式：


$$
P(\theta | data) \propto P(data | \theta) P(\theta)
$$

取 log：


$$
\log P(\theta | data) = \log P(data | \theta) + \log P(\theta) + \text{constant}
$$

直觉上：

$$
\text{MAP} = \text{似然} + \text{先验}
$$

### 1. 高斯先验与 L2

如果参数先验是高斯分布：


$$
w_j \sim N(0, \tau^2)
$$

会得到类似 L2 惩罚：


$$
\lambda \lVert w\rVert_2^2
$$

直觉：

```text
我先验上相信参数不应该太大。
```

### 2. 拉普拉斯先验与 L1

如果参数先验是拉普拉斯分布，会得到 L1 惩罚：


$$
\lambda \lVert w\rVert_1
$$

直觉：

```text
我先验上相信很多参数应该接近 0，甚至等于 0。
```

这解释了为什么 Lasso 能做稀疏选择。

## 九、信息论基础

### 1. 熵 Entropy

熵衡量不确定性。

离散分布熵：


$$
H(p) = -\sum_i p_i \log p_i
$$

直觉：

| 分布 | 不确定性 |
|---|---|
| 90% 上涨，10% 下跌 | 低 |
| 50% 上涨，50% 下跌 | 高 |

### 2. 交叉熵 Cross Entropy

交叉熵衡量：用预测分布 $q$ 表示真实分布 $p$ 的代价。


$$
H(p, q) = -\sum_i p_i \log q_i
$$

分类中，如果真实类别是 1，预测概率是 0.9，损失小；预测概率是 0.1，损失大。

二分类交叉熵：


$$
L = -[y \log p + (1-y) \log(1-p)]
$$

| 真实 y | 预测 p | 损失直觉 |
|---|---|---|
| 1 | 0.9 | 小 |
| 1 | 0.1 | 大 |
| 0 | 0.1 | 小 |
| 0 | 0.9 | 大 |

### 3. KL 散度


$$
\operatorname{KL}(p \parallel q) = \sum_i p_i \log(p_i / q_i)
$$

读法：

```text
用 q 去近似 p 时损失了多少信息。
```

KL 散度不是对称距离：


$$
\operatorname{KL}(p \parallel q) \ne \operatorname{KL}(q \parallel p)
$$

在机器学习中，KL 常用于：

- 概率模型。
- 变分推断。
- 蒸馏。
- 分布差异约束。

### 4. 信息增益

决策树要选择一个特征来分裂数据。信息增益衡量：

```text
分裂前不确定性 - 分裂后不确定性
```

公式直觉：


$$
\text{Information Gain} = H(\text{parent}) - \text{weighted average } H(\text{children})
$$

如果某个特征分裂后让类别更纯，信息增益就大。

### 5. Gini

Gini impurity：


$$
\operatorname{Gini} = 1 - \sum_k p_k^2
$$

Gini 越低，节点越纯。决策树常用 Gini 或熵来选择分裂。

## 十、典型算法连接

| 数学模块 | 算法 | 公式核心 |
|---|---|---|
| 梯度下降 | 线性模型、神经网络 | 参数沿负梯度更新 |
| 凸优化 | Ridge、逻辑回归、SVM | 全局最优更有保障 |
| 拉格朗日乘子 | PCA、组合优化 | 处理等式约束 |
| KKT | SVM、约束优化 | 处理不等式约束和支持向量 |
| 对偶问题 | SVM | 转换优化变量，引入核技巧 |
| MLE | 线性回归、逻辑回归 | 损失函数来自概率假设 |
| MAP | Ridge、Lasso | 正则化来自先验 |
| 交叉熵 | 分类模型 | 真实类别概率越低惩罚越大 |
| 信息增益/Gini | 决策树 | 选择最能降低不确定性的分裂 |

## 十一、常见误解与陷阱

| 误解 | 更准确的理解 |
|---|---|
| 损失函数是人为随便定义的 | 很多损失来自概率假设和 MLE |
| 梯度下降一定能找到全局最优 | 只有凸问题更有保障，神经网络通常非凸 |
| 学习率越大越快 | 太大会震荡或发散 |
| KKT 必须完整背熟 | 初学先理解约束、乘子、互补松弛直觉 |
| 交叉熵只是分类公式 | 它和最大似然、信息论都相关 |
| KL 散度是普通距离 | KL 不对称，不是严格距离 |
| 正则化只是防过拟合技巧 | 贝叶斯视角下它对应参数先验 |
| 对偶问题只是数学花活 | 它能让 SVM 引入核技巧并更方便求解 |

## 十四、术语表

| 术语 | 解释 |
|---|---|
| 目标函数 | 优化时要最小化或最大化的整体函数 |
| 损失函数 | 衡量单个样本或整体预测错误的函数 |
| 正则化 | 对模型复杂度的惩罚 |
| 梯度下降 | 沿负梯度方向迭代更新参数的方法 |
| SGD | 随机梯度下降，每次用部分样本估计梯度 |
| 凸函数 | 任意两点连线位于函数图像上方的函数 |
| 全局最优 | 整个可行域中最好的解 |
| 局部最优 | 附近范围内最好的解 |
| 约束优化 | 在满足条件下优化目标 |
| 拉格朗日乘子 | 把约束加入目标函数的工具 |
| KKT | 约束优化的一组必要条件 |
| 对偶问题 | 与原优化问题相关的另一个优化问题 |
| 核技巧 | 用核函数计算高维映射后的内积 |
| MLE | 极大似然估计 |
| MAP | 最大后验估计 |
| 先验 | 看到数据前对参数的假设 |
| 后验 | 结合数据后的参数分布 |
| 熵 | 不确定性的度量 |
| 交叉熵 | 预测分布相对真实分布的编码代价 |
| KL 散度 | 两个概率分布的差异度量 |
| 信息增益 | 分裂前后不确定性下降量 |
| Gini | 决策树中衡量节点不纯度的指标 |

## 十五、延伸阅读

- 凸优化：先看无约束优化、拉格朗日乘子、KKT 直觉。
- 统计学习：重点理解 MLE 如何导出平方损失和交叉熵。
- ESL 前四章：线性模型、正则化、分类方法。
- SVM 教程：重点看间隔最大化、对偶和核技巧，不必一开始深究泛函分析。
- 决策树：重点看熵、信息增益、Gini 的分裂逻辑。
